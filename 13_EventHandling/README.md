# 13. イベント処理

## 目的
ボタンクリックなどのユーザー操作にプログラムが応答する仕組み(イベント駆動)を
理解し、シグナル・スロット/コールバックによる処理の結びつけ方を身につける。

## 学習ポイント
- イベント駆動プログラミングの基本モデル
- シグナル・スロット(Qt)またはコールバック/イベントハンドラの登録
- 複数ウィジェット間でのイベント連携（例: ボタン押下でラベルの表示を変える）

## 推奨ライブラリ/ツール
- Qt6（`connect`によるシグナル・スロット）

本課題では**Win32 API**を採用する。理由はルート [README.md](../README.md#guiライブラリの選定について) を参照。
Win32では`WM_COMMAND`メッセージが(コントロールID, 通知コード)の組を運び、Qtの
シグナル・スロットに相当する「どの操作にどう応答するか」の振り分けを担う。

## 成果物イメージ
テキストボックスに入力した内容が、ボタンを押すたびに別のラベルに反映される
簡単な双方向インタラクションアプリ。

## ビルド方法・実行方法

他の課題と同様にCMakeを使う（詳細はルート [README.md](../README.md#cmakeとvisual-studioの使い分け) を参照）。

```sh
# 13_EventHandling ディレクトリで実行
cmake --preset x64-debug
cmake --build --preset x64-debug
./out/build/x64-debug/EventHandling
```

## 構成と学習ポイントとの対応

| 要素 | 内容 | 学習ポイント |
|---|---|---|
| `WM_COMMAND`ハンドラで`(id, notificationCode)`を判定 | イベント駆動の基本モデル | イベント駆動プログラミングの基本モデル |
| `OnReflectButtonClicked` | ボタンの`BN_CLICKED`をコールバックとして処理 | コールバック/イベントハンドラの登録 |
| `GetWindowText(edit)` → `SetWindowText(label)` | テキストボックス→ラベルへの連携、反映回数のカウント表示 | 複数ウィジェット間でのイベント連携 |

## 動作確認

ビルド・実行し、`EnumChildWindows`で全コントロールの構造を確認した上で、
`WM_SETTEXT`でテキストボックスに値を設定→`BM_CLICK`でボタン押下を模擬送信→
`GetWindowText`で結果ラベル・カウンターを読み出す、という一連の自動操作で
以下を確認済み。

- `"First"`入力→反映 → 結果ラベルが`"First"`、反映回数が`1`になる
- 続けて`"Second"`入力→反映 → 結果ラベルが`"Second"`、反映回数が`2`になる（連続操作）
- 空入力で反映 → 結果ラベルが`"(空の入力が反映されました)"`、反映回数が`3`になる
