# 13. イベント処理

## 目的
ボタンクリックなどのユーザー操作にプログラムが応答する仕組み(イベント駆動)を
理解し、シグナル・スロット/コールバックによる処理の結びつけ方を身につける。

## 学習ポイント
- イベント駆動プログラミングの基本モデル
- シグナル・スロット(Qt)またはコールバック/イベントハンドラの登録
- 複数ウィジェット間でのイベント連携（例: ボタン押下でラベルの表示を変える）

## 推奨ライブラリ/ツール
- Qt6（`connect`によるシグナル・スロット）

## 成果物イメージ
テキストボックスに入力した内容が、ボタンを押すたびに別のラベルに反映される
簡単な双方向インタラクションアプリ。
