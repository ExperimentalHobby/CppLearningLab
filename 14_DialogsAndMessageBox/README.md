# 14. ダイアログ

## 目的
モーダル/モードレスダイアログとメッセージボックスの使い分けを理解し、
ユーザーへの確認・警告・入力要求を適切に実装できるようになる。

## 学習ポイント
- モーダルダイアログとモードレスダイアログの違い
- メッセージボックス（情報・警告・エラー・確認）
- ダイアログとメインウィンドウ間のデータの受け渡し

## 推奨ライブラリ/ツール
- Qt6 (`QDialog`, `QMessageBox`)

## 成果物イメージ
「削除しますか?」といった確認ダイアログや、簡単な入力フォームを持つ
カスタムダイアログを表示し、結果をメインウィンドウに反映するアプリ。
