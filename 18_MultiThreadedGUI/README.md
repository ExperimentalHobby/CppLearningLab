# 18. マルチスレッドGUI

## 目的
時間のかかる処理をUIスレッドをブロックせずに実行し、進捗をGUIに反映する
非同期処理の設計を身につける。

## 学習ポイント
- UIスレッドとワーカースレッドの分離（GUIツールキットは基本的にUIスレッド以外から
  直接ウィジェットを操作できないことの理解）
- スレッド間通信（Qtの`QThread`+シグナル・スロット、またはstd::threadとイベントキュー）
- プログレスバーへの進捗反映、キャンセル処理

## 推奨ライブラリ/ツール
- Qt6 (`QThread`, `QProgressBar`) または `std::thread` + 独自のスレッドセーフキュー

## 成果物イメージ
「重い処理」（ダミーのファイルコピーや計算処理）をバックグラウンドスレッドで実行し、
進捗バーに反映しつつ、UIは操作可能なまま保たれるアプリ。
